FLY.IO DEPLOY (same stack as local; Dockerfile-based, portable to Railway etc.)
==============================================================================

Layout:
  deploy/
    docker/          <- Dockerfiles (db, supavisor, meta, analytics, studio) — used by Fly & Railway
    fly/             <- Fly-only: fly.toml per app, Kong Dockerfile + config
    railway/         <- Railway notes (see README there)
    set-secrets-from-env.sh   <- Sync docker/supabase/.env to Fly secrets

Prereqs: flyctl installed, fly auth login, one org. Pick a region (e.g. ord) and use it for all apps.

--- 1. DB ---
# From docker/supabase/:
cd deploy/fly/db
fly launch --no-deploy --copy-config --name commandra-db --region ord
fly volumes create pgdata --size 10 --region ord
cd ../..
./set-secrets-from-env.sh db
cd fly/db && fly deploy
cd ../..
# Wait: fly status

--- 2. Supavisor ---
cd fly/supavisor
fly launch --no-deploy --copy-config --name commandra-supavisor --region ord
cd ../..
./set-secrets-from-env.sh supavisor
cd fly/supavisor && fly deploy && cd ../..

--- 3. Meta ---
cd fly/meta
fly launch --no-deploy --copy-config --name commandra-meta --region ord
cd ../..
./set-secrets-from-env.sh meta

--- 4. Analytics ---
cd fly/analytics

cd ../..

cd fly/analytics && fly deploy && cd ../..

--- 5. Studio ---
cd fly/studio
fly launch --no-deploy --copy-config --name commandra-studio --region ord

--- 6. Kong ---
cd fly/kong

cd fly/kong && fly deploy && cd ../..

--- 7. Custom domain ---
fly certs add db.commandra.app -a commandra-kong
# Add CNAME/A record Fly shows for db.commandra.app.

--- 8. Commandra prod DATABASE_URL ---
postgresql://postgres.commandra:YOUR_POSTGRES_PASSWORD@commandra-supavisor.flycast:5432/postgres
(Use the same POSTGRES_PASSWORD as in docker/supabase/.env. Get host from: fly status -a commandra-supavisor.)

--- 9. Migrations ---
DATABASE_URL="postgresql://postgres.commandra:PASSWORD@commandra-supavisor.flycast:5432/postgres" pnpm db:migrate

--- 10. Studio ---
https://db.commandra.app — login: DASHBOARD_USERNAME / DASHBOARD_PASSWORD from .env.

Secrets: run ./set-secrets-from-env.sh (from deploy/) or set in Fly UI per app — see SECRETS-FOR-UI.txt for the list.
